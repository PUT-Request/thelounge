# Responsible Disclosure of Security Vulnerabilities

- ⚠️ **Do not open public issues on GitHub to report security vulnerabilities.**
- Contact us privately first, in a
  [responsible disclosure](https://en.wikipedia.org/wiki/Responsible_disclosure)
  manner.
- Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  on [PUT-Request/thelounge](https://github.com/PUT-Request/thelounge/security/advisories/new).

Upstream [`thelounge/thelounge`](https://github.com/thelounge/thelounge)
vulnerabilities that also affect this fork should additionally be reported
upstream following [their process](https://github.com/thelounge/thelounge/blob/master/SECURITY.md).
